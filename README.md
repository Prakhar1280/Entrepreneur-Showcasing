# Interactive Entrepreneur Showcase: Alex Karp
**EDC JSS University Technical Team Recruitment 2026 — Task 02 (Second-Year Applicant)**

An interactive, responsive single-page web application exploring the trajectory, ventures, and impact of Dr. Alexander Caedmon Karp, co-founder and CEO of Palantir Technologies.

---

## Features
- **Dynamic Milestones Timeline:** 5 chronological milestones rendered dynamically via a structured JavaScript data array.
- **Interactive Venture Explorer:** Venture and product cards with interactive category filtering (All, Enterprise, Defense, Finance).
- **Impact & Takeaways:** Analyzes Karp's contribution to defense software and core lessons for aspiring founders.
- **Responsive Architecture:** Accessible across desktop, tablet, and mobile browsers.
